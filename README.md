# WebbportföljEC

A personal web portfolio for presenting who I am, what I am learning, and the projects I build during my journey toward becoming a .NET developer.

## About the Project

This portfolio is built as part of my studies in dynamic web applications. The goal is to create a personal website where I can showcase my technical skills, projects, background, and contact information in one place.

The design is personal, hand-drawn inspired, and built with a warm color palette to reflect both creativity and professionalism.

## Features

- Sticky navigation bar
- Section-based navigation
- Hero section with custom doodle graphic
- Skills section
- Projects section
- About me section
- Testimonials section
- Contact form

## Built With

- HTML
- CSS
- JavaScript
